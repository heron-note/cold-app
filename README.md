# キンキン

触れるほど、寒くなる。コードも持ってけ。

Web 公開用の静的ファイル一式です（Flutter ソースは含みません）。

## 公開手順

1. このフォルダ（`deploy/`）の**中身**を、リポジトリ `cold-app` のルートへアップロード
2. Settings → Pages → Deploy from a branch → `main` / `/ (root)`

公開URL: `https://<username>.github.io/cold-app/`
